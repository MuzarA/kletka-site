# Сайт студии «Клетка»

Сайт-портфолио студии браузерных игр на трёх языках: русском, кыргызском и английском. Три игры («Виселица на двоих», «Finish the Word», «Морской бой») запускаются прямо на сайте. Ещё на сайте есть раздел о студии, команда с рейтингом, галерея и форма консультации. Заявки и оценки разработчиков приходят в Telegram-бота.

## Что в папке

```
index.html, styles.css, app.js   — сайт
config.js                        — ВСЕ ДАННЫЕ: название, контакты, игры, ссылки, команда, галерея (на 3 языках)
i18n.js                          — тексты интерфейса сайта на русском, кыргызском и английском
games/                           — игры
  hangman.js, wordchain.js, battleship.js   — код игр
  games.css                                 — оформление игр
  words-en.txt                              — словарь для Finish the Word (112 тыс. слов)
  hangman.html, wordchain.html, battleship.html — каждая игра отдельной страницей
images/team/      — фото команды (сейчас пиксельные заглушки)
images/screens/   — скриншоты для галереи
api/              — обработчики для Vercel: lead.js (заявки), rate.js (оценки), ratings.js (рейтинг)
send.php, rate.php, ratings.php, tg_lib.php — то же для обычного PHP-хостинга
data/             — тут PHP-версия хранит рейтинг (закрыта от браузера)
```

## 1. Заполните свои данные

Всё меняется в `config.js`:

- **studio**: название, почта, Telegram, GitHub;
- **games**: описания игр, ссылки на онлайн-версию (`online`) и репозиторий (`repo`);
- **team**: имена, роли, фото, навыки, ссылки. Поле `id` не меняйте после запуска, по нему хранятся оценки. `founder: true` добавляет отметку «Основатель»;
- **gallery**: фото и подписи. Свои фото положите в `images/`.

Ссылки на GitHub, имена и фото команды сейчас примерные, их нужно заменить.

## Языки

- Переключатель RU / KY / EN стоит в шапке. Выбор запоминается в браузере посетителя.
- Ссылка с языком: `https://ваш-сайт/?lang=ky` или `?lang=en`.
- Тексты разделов лежат в `i18n.js`. Названия, описания игр и данные команды лежат в `config.js`, в виде `{ ru: "...", ky: "...", en: "..." }`.
- Игры тоже переведены. В «Виселице» на каждом языке свои слова и своя клавиатура (на кыргызском есть Ң, Ө, Ү). «Finish the Word» всегда играется английскими словами, переведено только меню.
- В Telegram заявки приходят на русском. Строка «Язык сайта» показывает, на каком языке писал клиент.
- Кыргызские тексты стоит показать носителю языка и поправить в `i18n.js` и `config.js`.

## 2. Создайте Telegram-бота

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot` и получите **токен**.
2. Узнайте **chat id**, куда будут приходить сообщения:
   - **себе лично:** напишите своему боту любое сообщение и откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`. Число в `"chat":{"id": ...}` и есть ваш chat id.
   - **в группу команды:** добавьте бота в группу, напишите там что-нибудь и так же откройте `getUpdates`. У групп id начинается с `-100`.
3. Можно указать несколько chat id через запятую.

В бота будут приходить два вида сообщений:
- 🟥 **Новая заявка на консультацию**: имя, контакт (Telegram-ник кликабельный), что нужно, бюджет, описание;
- ⭐ **Новая оценка разработчику**: кто, сколько звёзд, отзыв и рейтинг после этой оценки.

Токен **никогда не вставляйте в `config.js` или `app.js`**, их видит любой посетитель. Токен хранится только на сервере.

## 3а. Запуск на Vercel (бесплатно, рекомендуется)

1. Загрузите папку в репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) нажмите **Add New → Project**, выберите репозиторий и нажмите **Deploy**. Настройки сборки не нужны.
3. Откройте **Settings → Environment Variables** и добавьте:
   - `TELEGRAM_BOT_TOKEN`: токен бота;
   - `TELEGRAM_CHAT_ID`: chat id.
4. **Чтобы рейтинг сохранялся:** откройте **Storage → Create → Upstash for Redis** (есть бесплатный тариф) и подключите хранилище к проекту. Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
   Без этого шага оценки всё равно приходят в Telegram, но рейтинг на сайте не накапливается.
5. Откройте **Deployments → Redeploy**, чтобы применить переменные.
6. Отправьте тестовую заявку и оценку и проверьте, что они пришли в Telegram.

## 3б. Обычный хостинг с PHP

1. Загрузите все файлы, кроме папки `api/`.
2. В `config.js` поменяйте адреса:
   ```js
   formEndpoint: "send.php",
   rateEndpoint: "rate.php",
   ratingsEndpoint: "ratings.php",
   ```
3. Задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в панели хостинга. Если панель этого не умеет, впишите значения в начало `tg_lib.php`.
4. Папка `data/` должна быть доступна PHP для записи (обычно права 750 или 755).

## Защита

- скрытое поле-ловушка для ботов в обеих формах;
- не больше 5 заявок и 10 оценок с одного IP за 10 минут;
- одна оценка разработчику с одного IP раз в 180 дней, а в браузере кнопка «Оценить» после оценки скрывается;
- HTML в тексте экранируется, длина полей ограничена.

## Игры

- Игры работают без сервера и без интернета после загрузки страницы. Нужен только `words-en.txt` рядом с `wordchain.js`.
- Ссылка вида `https://ваш-сайт/#play-battleship` сразу открывает игру.
- Каждую игру можно открыть отдельной страницей: `games/hangman.html`, `games/wordchain.html`, `games/battleship.html`.
- Онлайн-версии с комнатами по коду работают внутри Claude. Ссылки на них стоят в `config.js` (`online`). Чтобы друзья могли их открыть, включите в Claude доступ по ссылке через меню Share.
